# ระบบจัดการซ่อมและติดตามเครื่องจักรกลการเกษตร (ทรัพเจริญการช่าง)

React (Vite + Tailwind) + Express + PostgreSQL

## สิ่งที่ต้องมี
- Node.js 18 ขึ้นไป
- PostgreSQL (เปิดใช้งานอยู่ และรู้รหัสผ่านของผู้ใช้ `postgres`)

## ติดตั้งครั้งแรก
1. เปิดโฟลเดอร์นี้ใน VS Code แล้วเปิด Terminal
2. สร้างไฟล์ `.env` จากตัวอย่าง
   ```
   Copy-Item .env.example .env
   ```
   แล้วเปิด `.env` แก้ 3 ค่า
   - `DB_PASSWORD` = รหัสผ่าน PostgreSQL
   - `JWT_SECRET`  = ข้อความสุ่มยาวอย่างน้อย 16 ตัว
   - `OWNER_PASSWORD` = รหัสผ่านสำหรับล็อกอิน (อย่างน้อย 8 ตัว)
3. ติดตั้งไลบรารี
   ```
   npm install
   ```
4. สร้างฐานข้อมูล ตาราง บัญชีเจ้าของกิจการ และข้อมูลตัวอย่าง
   ```
   npm run db:seed
   ```
   (ถ้าไม่ต้องการข้อมูลตัวอย่างให้ใช้ `npm run db:init`)

## เปิดใช้งานทุกครั้ง (เปิด 2 เทอร์มินัล)
```
npm run server     # หลังบ้าน  http://localhost:5000
npm run dev        # หน้าเว็บ   http://localhost:5173
```
ล็อกอินด้วย `owner` และรหัสผ่านที่ตั้งใน `OWNER_PASSWORD` (หน้าล็อกอินสำหรับเจ้าของอู่ ไม่ต้องเลือกบทบาท)

## คำสั่งอื่น
| คำสั่ง | ทำอะไร |
|---|---|
| `npm run db:init` | สร้าง/อัปเดตตาราง (รันซ้ำได้ ไม่ลบข้อมูล) |
| `npm run db:seed` | เหมือน db:init และใส่ข้อมูลตัวอย่างถ้าตารางรถยังว่าง |
| `npm run db:reset` | ลบตารางทั้งหมดแล้วสร้างใหม่ (ข้อมูลหาย ต้องพิมพ์ RESET ยืนยัน) |
| `npm run build` | สร้างหน้าเว็บสำหรับใช้งานจริง (โฟลเดอร์ dist ให้ server.js เสิร์ฟให้เอง) |

สำรองข้อมูล: `pg_dump -U postgres rice_harvester_db > backup.sql` และคัดลอกโฟลเดอร์ `uploads` ไปด้วย

## โครงสร้างไฟล์
- `server.js` — API หลังบ้าน (ล็อกอิน JWT, รถ, ประวัติซ่อม, รูปถ่าย, ลูกค้า, ติดตามหลังซ่อม, แจ้งเตือน, ผู้ใช้, รายงาน)
- `validate.js` — ตรวจข้อมูลที่ส่งมาจากหน้าเว็บ
- `db-init.js`, `schema.sql`, `seed-demo.sql` — สร้างฐานข้อมูล ตาราง และข้อมูลตัวอย่าง
- `src/App.jsx` — หน้าเว็บทั้งหมด
- `src/api.js` — ตัวเรียก API ของหลังบ้าน

## ฟีเจอร์ของอู่ซ่อม
- **รถในระบบ → ดูประวัติซ่อมรายคัน**: แยกตามปี (พ.ศ.) และเดือน มีกราฟค่าซ่อมรายเดือน รูปถ่าย รายการอะไหล่ และราคา
- **บันทึกงานซ่อม**: แนบรูปก่อน/หลังซ่อมได้สูงสุด 12 รูปต่องาน (ระบบย่อรูปให้อัตโนมัติ) และตั้งนัดติดตามหลังซ่อม
- **ลูกค้า**: เก็บชื่อ เบอร์โทร และ LINE ID ผูกกับรถแต่ละคัน
- **ติดตามหลังซ่อม**: รายการนัดโทร/ทัก LINE มีปุ่มโทร ปุ่มเปิด LINE และข้อความสำเร็จรูปให้คัดลอก แล้วบันทึกผลการติดตาม
- รูปถ่ายเก็บเป็นไฟล์ในโฟลเดอร์ `uploads/` (ในฐานข้อมูลเก็บแค่ชื่อไฟล์) **ต้องสำรองโฟลเดอร์นี้คู่กับ `pg_dump` เสมอ**
- **แชต LINE**: คุยกับลูกค้าผ่าน LINE Official Account ของอู่ได้ในระบบ (รับ-ส่งข้อความ รับรูปที่ลูกค้าส่งมา) ดูวิธีตั้งค่าด้านล่าง
- **สมัครสมาชิก**: หน้าล็อกอินมีปุ่มสมัคร บัญชีใหม่เป็น "รออนุมัติ" เจ้าของอู่อนุมัติและกำหนดสิทธิ์ที่เมนู ตั้งค่า > ผู้ใช้

## ตั้งค่า LINE (แชตกับลูกค้า)
LINE Notify เลิกให้บริการแล้ว ต้องใช้ LINE Official Account + Messaging API
1. สมัคร LINE Official Account ที่ manager.line.biz แล้วเปิดใช้ Messaging API (เมนูตั้งค่า > Messaging API)
2. ที่ developers.line.biz เปิด Channel นั้น คัดลอก **Channel secret** (แท็บ Basic settings) และกด Issue **Channel access token (long-lived)** (แท็บ Messaging API)
3. ใส่ในไฟล์ `.env`
   ```
   LINE_CHANNEL_SECRET=...
   LINE_CHANNEL_ACCESS_TOKEN=...
   ```
   แล้วปิด/เปิด `npm run server` ใหม่
4. LINE ต้องเรียกเข้ามาที่เซิร์ฟเวอร์ผ่าน HTTPS สาธารณะ ตอนทดลองบนเครื่องตัวเองใช้อุโมงค์ชั่วคราว เช่น
   ```
   winget install Cloudflare.cloudflared
   cloudflared tunnel --url http://localhost:5000
   ```
   จะได้ลิงก์ `https://xxxx.trycloudflare.com` (เปลี่ยนทุกครั้งที่เปิดใหม่) ใช้งานจริงควรวางระบบบนเซิร์ฟเวอร์ที่มีโดเมนและ HTTPS ถาวร
5. ในแท็บ Messaging API ใส่ Webhook URL = `https://xxxx.trycloudflare.com/api/line/webhook` กด Verify แล้วเปิด Use webhook
6. ปิด Auto-reply / Greeting message ของ LINE OA ถ้าไม่ต้องการให้ตอบซ้ำซ้อน
7. ให้ลูกค้าเพิ่มเพื่อนกับบัญชีของอู่แล้วทักมา จะเห็นชื่อในเมนู "แชต LINE" จากนั้นเลือกว่าเป็นลูกค้าคนไหนในระบบ (ใช้ติดตามหลังซ่อมได้ทันที)

ข้อควรรู้: ข้อความที่อู่ส่งออกนับโควตาข้อความรายเดือนตามแพ็กเกจของ LINE OA ตรวจราคาและโควตาล่าสุดที่ LINE for Business ประเทศไทย ส่วนข้อความที่ลูกค้าส่งเข้ามาไม่นับโควตา และระบบจะส่งหาได้เฉพาะคนที่เพิ่มเพื่อนไว้และไม่ได้บล็อก

## อัปเดตจากเวอร์ชันก่อนโดยไม่เสียข้อมูล
```
npm install
npm run db:init     # เพิ่มตารางลูกค้า/รูป/ติดตามหลังซ่อม ข้อมูลเดิมอยู่ครบ
```

## สิทธิ์การใช้งาน
- เจ้าของกิจการ: ทำได้ทุกอย่าง รวมถึงรายงานและจัดการผู้ใช้
- ช่างซ่อม: เพิ่ม/แก้รถ ประวัติซ่อม แจ้งเตือน
- พนักงานขับรถ: ดูข้อมูลรถอย่างเดียว

ความปลอดภัย: ห้ามอัปโหลดไฟล์ `.env` ขึ้น GitHub (ถูกกันไว้ใน `.gitignore` แล้ว)
